# Bezpieczeństwo

## Zgłaszanie podatności

Nie publikuj informacji o aktywnej podatności w zwykłym zgłoszeniu. Użyj prywatnego zgłoszenia **Security → Report a vulnerability** w repozytorium GitHub.

Dołącz wersję aplikacji, wersję Windows, opis wpływu i minimalne kroki odtworzenia. Nie wysyłaj prawdziwych ciasteczek, tokenów ani danych logowania.

## Zakres

Projekt obejmuje kod aplikacji i instalatora. `yt-dlp`, FFmpeg i Deno są pobierane z oficjalnych lokalizacji, weryfikowane sumami SHA-256 i podlegają własnym procesom bezpieczeństwa.
